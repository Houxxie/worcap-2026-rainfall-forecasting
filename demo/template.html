How to read these results

Two LightGBM models and local ridge regression are combined with fixed weights of 37.5%, 37.5% and 25%. Each historical block uses its own earlier training window. These metrics do not score the map above or represent the competition's final score.

The cards pool errors across all validation years; global RMSE is not an average of yearly RMSE. These development years have already been consulted, so the results do not establish performance in future years. Full competition validation maps are not bundled.

Model and data sources

The registered model uses two LightGBM models and local ridge regression, fitted on 1993–2022 with weights of 37.5%, 37.5% and 25%. Atmospheric inputs use T−4, ocean indices T−3 and seasonal initializations T−1. Required sources passed their checks before issuance.

Local receipt times and file hashes are preserved in the registry; they are not an independent external timestamp.

How to read these results

Each historical block uses its own earlier training window with longer input lags. These metrics do not score the October forecast or evaluate the final 1993–2022 fit on earlier years. The cards pool errors across all validation years; global RMSE is not an average of yearly RMSE.

The source-lag protocol differs from the competition model, so the two tabs are not a controlled paired comparison. These development years have already been consulted, so the results do not establish performance in future years. U-Net and global SST/PCA remain separate experiments.
